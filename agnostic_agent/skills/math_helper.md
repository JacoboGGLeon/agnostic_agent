# Math Helper

Usa estas tools cuando el usuario pida calculos o transformaciones matematicas:
- `eval_math_expression` para expresiones.
- `sum_numbers` para sumar listas.
- `average_numbers` para promediar listas.

No inventes datos: si faltan numeros, pide aclaracion.
